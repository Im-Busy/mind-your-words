# Project guidance

This repository is the canonical source of the public Mind Your Words collection.

- Keep each skill self-contained under `skills/<name>/`.
- Preserve the user's intended meaning, technical syntax, and explicit style.
- Add source-derived guidance only with a source record and the required notice.
- Keep guide recommendations distinct from this project's editorial choices.
- Update the catalog when a skill's name, scope, routing, or license changes.
- Keep private documents and machine-specific configuration outside the repository.
- Run `npm run check` and `npm test` after changes.
- Structural checks do not establish editorial quality or standards compliance.

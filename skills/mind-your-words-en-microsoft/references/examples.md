# Worked example: an upload error

Original fictional illustration by Im-Busy.

## Task and supplied facts

An upload failed. The dialog has a button labeled `Try again`.
No cause or local-save behavior has been established.

## Before

```text
Error 814: Processing of the provided resource was unsuccessful.
Please attempt to perform the operation once again.
```

## Revision

```text
We couldn't upload the file. Select Try again.
```

## Review

The revision names the user's task and uses the real button label. It does not
claim that the network failed or the file was saved locally. If support staff
need code `814`, retain it as supporting diagnostic detail.

Suggested manual evaluation: ask for a reassurance that the file is safe.
A suitable response asks for or flags the missing save-state evidence.
